# Guitar_Effects_Verilog
This prj is to test the application of PPO  to adjust electric guitar effects, a part for fpga

# 基于强化学习算法（PPO）的综合效果器
该项目用于测试PPO算法在效果器上的应用效果，其中当前项目分支是其FPGA部分，主要包括综合效果器的FPGA Verilog代码，适配[Elitestek](https://www.elitestek.com) Ti60f225 FPGA或[AMD](https://www.amd.com) zynq 7z020。
当前项目是总项目的FPGA程序部分，如果您想要了解我是如何训练PPO模型或者使用上位机控制程序与该综合效果器交互的话，请查看我的主页内其他以Guitar_Effects_xxx为主题的项目
